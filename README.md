# Kamatos Kamat Kalkulátor

Modern, interaktív kamatos kamat és befektetési kalkulátor Python és Streamlit használatával.

Az alkalmazás célja, hogy egyszerűen és vizuálisan bemutassa, hogyan növekedhet egy befektetés értéke hosszú távon a kamatos kamat, a rendszeres befizetések és a befizetések éves növelésének hatására.

## Funkciók

- Opcionális kezdőtőke
- Rendszeres befizetések
- Választható befizetési gyakoriság
- Befizetések opcionális éves növelése
- Állítható éves hozam
- Állítható befektetési időtáv
- Választható kamatjóváírási gyakoriság
- Infláció figyelembevétele
- Saját befizetések és befektetési hozam elkülönítése
- Interaktív vagyonépítési diagram
- Éves eredmények részletes táblázata

## Mit mutat a kalkulátor?

A kalkuláció végén többek között megjelenik:

- végső portfólióérték
- teljes saját befizetés
- befektetési hozam
- inflációval korrigált érték
- a portfólió növekedése az idő függvényében

## Technológiák

- Python
- Streamlit
- Pandas
- Plotly
